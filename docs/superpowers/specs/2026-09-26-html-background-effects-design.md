# 参考 HTML 自然背景效果迁移

## 目标与范围

按用户确认，在当前正式首页 Canvas 场景迁移参考 HTML 的自然背景表达，重点是日出暖光与山脊的空间关系。独立 Three.js 山谷预览仍按其分阶段计划验收，本次不改它。

写入范围：`apps/web/src/scene/flow/painter.ts`、必要时 `palette.ts`、场景绘制测试及视觉质量记录。每次只改一个背景问题；不重写场景，不把附件 HTML 作为运行时、构建输入或依赖。

## 设计

- **自由／默认**：保留真实环境时间驱动的山水背景；使用天空渐变、太阳、远近山脊和水面的因果层次表现日出。日出时低地平线暖光与太阳贴近远山升起，远山保持低对比，山形稳定且有层次。
- **工作**：真实刚性事件开始时使用低强度、可逆的背景氛围变化；不移动太阳、不更改场景时间、不压暗到影响阅读。
- **紧急**：仅真实提前提醒未确认时增强已有局部边缘提醒；确认后立即撤下。不搬原 Demo 全屏红色滤镜、呼吸框或闪烁。
- 三种状态是服务端事件与提醒事实驱动的视觉状态，不显示模式标签/按钮。删除/不迁入时间轴、手动模式、虚构事件、加速时钟、“开始一天”等 Demo UI 与逻辑。
- 色彩继续以 `EnvironmentFrame` 的太阳高度、天气透射和季节输入为准；状态效果不能改写天文或天气因果。

## 验收

1. 固定时刻可重复绘制；日出截图可见暖色地平线、太阳与远山的遮挡/前后关系，山形不随机变化。
2. 白天、夜间仍连续衔接；天气只影响透射/天空与山体光色，不移动太阳。
3. 自由是默认效果；WORK 只在实际事件 active 时进入；URGENCY 只在提醒未确认时出现，确认立即撤下。
4. 没有自由/工作/紧急模式按钮、常驻时钟、时间轴或模拟时钟。
5. Web 构建与场景测试通过；记录日出、白天、夜间的浏览器画面，代码测试不替代视觉验收。
