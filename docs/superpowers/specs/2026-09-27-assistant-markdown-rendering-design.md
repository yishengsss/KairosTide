# 助手回复 Markdown 渲染

## 状态与范围

用户确认：只将 Kairos 助手回复按常见 Markdown 格式渲染；用户原文继续纯文本显示；结构化操作结果卡片保持现状。

范围限于 Web 对话消息渲染与相关测试，可增加一个 Markdown parser 依赖；不改 API 对话文本、操作卡片、会话状态或后端。

## 实现

- 在 `Conversation.vue` 使用标准 Markdown parser，支持常用标题、段落、粗体/斜体、无序/有序列表、引用、行内代码、代码块和链接。
- 原始 HTML 禁止并转义；不要将模型返回值直接作为原始 `v-html` 插入。
- Markdown 图片不发起远程请求，显示其替代文字，避免外部追踪与任意资源加载。
- 链接只允许安全协议；外链使用 `noopener noreferrer`，不能执行脚本协议。
- 只处理 `role === 'assistant'` 的 `content`；用户消息继续由 Vue 插值转义。操作结果、刚性变更提案、任务与日程卡片仍使用现有结构化模板。

## 验收

1. Kairos 回复中的列表、粗体、链接和代码按 Markdown 排版。
2. 用户消息中的 Markdown 符号仍显示为普通文本。
3. 原始 `<script>`/HTML 不执行或注入；`javascript:` 链接和远程图片不会被加载。
4. 操作成功/失败回执与刚性日程提案仍由现有结构化卡片渲染。
5. 运行助手组件测试及 Web 构建。
