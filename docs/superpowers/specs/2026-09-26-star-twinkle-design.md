# 星点柔和闪烁

## Goal

让夜间星空有轻微可察觉的生命感，同时保留宁静与星位稳定。

## Design

- 仅调整 `apps/web/src/scene/flow/painter.ts` 的星点透明度时间函数及对应 scene 测试。
- 星点坐标、大小和数量保持确定、固定；不增加漂移、颜色变化、光晕或流星。
- 仅在夜间星点可见时，以彼此错开的缓慢周期轻柔改变亮度；维持非零基础亮度，避免消失/闪烁感。
- 继续使用现有 Canvas 帧循环；`prefers-reduced-motion` 下循环停止、星点保持静态。
- 用途为环境状态的细微表现；不影响输入、事件和其他场景层。

## Acceptance

1. 固定场景时刻与尺寸重复绘制仍有确定的星位。
2. 夜间跨时间采样星点透明度会变化，且不出现全灭或突跳。
3. 白天星点仍隐藏；减少动态效果下时间推进不改变星点绘制。
4. 相应 scene 测试通过；其他场景层保持原有输入与输出。
