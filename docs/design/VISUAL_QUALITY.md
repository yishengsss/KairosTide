## 美术基线

- 目标是安静、可信、可以长时间停留的山水环境。写实感优先来自光照和空间关系，不以堆叠模糊、粒子或高光代替。
- 固定一个湖岸构图；天空为主体，山脉承担中景、水面承接光源。中央保留低纹理区域供事件短暂出现。
- 同一时刻只有统一的主光方向。云遮太阳时，太阳可见度、山体受光和水面反光共同变弱；远山比近岸对比低。
- 倒影与波纹必须经过水域遮罩；前景、近岸、文字上不能出现湖面高光。雾按景深降对比，不用白色蒙版压平所有图层。
- 横屏与竖屏共享场景语义，分别调整裁切与主体位置；所有图层使用同一转换，不把山体、水域和粒子各自按屏幕百分比猜位置。
- 山水保持静止构图；太阳、天光连续变化，水面只作局部低幅运动。云、天气粒子是次要运动，不能争夺太阳与事件信息的注意力。
- 默认没有装饰性文案、阶段标签、发光描边、鼠标追随、镜头推拉、随机布局或不断弹跳的入口。
- UI 使用系统字体与一种一致的表面材质；透明度服务于可读性，避免多个玻璃层叠加。故障状态低权重且有明确操作。

## 动效准入

新增动效先写明：用途、触发条件、作用区域、时长/速度、退出方式、被打断时的行为、减少动态效果版本、后台恢复方式。缺任一项先不启用。

| 对象 | 建议基线 | 不接受 |
| --- | --- | --- |
| 天光/天体 | 真实环境时间连续推进，样式更新从当前画面接续 | 走一段停一段；真实日程动画混用 Demo 时钟 |
| 水光 | 低对比、稀疏、位于水面，随光源位置调整 | 等距梯子、平行激光线、岸上反光 |
| 云 | 极慢单向漂移，离屏或不可见时接续 | 自动往返、同步摇摆的棉花团 |
| 雨雪 | 降水粒子强度受天气驱动，数量有上限，速度/远近一致；冬季地面积雪可由季节驱动 | 凭季节制造降雪粒子；粒子覆盖功能文字 |
| 飞鸟 | 当前先不启用旧摆动版；后续单次穿越，有方向和自然离场 | 反复左右摆动、在画面中央永远悬停 |
| 提醒 | 局部平滑增强后维持；确认即时响应 | 全屏呼吸、闪烁、抖动、改变太阳或天空色相 |
| AI 面板 | 建议 200–250ms，`cubic-bezier(0.32, 0.72, 0, 1)`，同路进出、可反向 | 无手势也弹跳；离场先清空内容；输入被禁用等动画结束 |
| 事件/查时信息 | 短淡入淡出，先确保字号、位置和对比稳定 | 打字机、逐字飞入、百分比圆环、画面旋转 |

长时间环境变化不套用按钮的短时长；短 UI 也不套用环境的十几秒过渡。不新增动效库只为普通淡入淡出。需要真实拖拽时再评估连续跟手与速度继承。
减少动态效果时停掉位移、循环及粒子，保留必要的静态信息/温和淡化；降低透明度偏好时使用实色表面。后台暂停装饰循环，恢复读取现在，不补播历史。

## 约束 AI 与实现代理

1. 设计负责人维护构图、颜色关系和动效清单；实现代理一次只修改一个已定义问题，不同时重新发明山形、天气、控件样式。
2. 固定几何与确定性种子，禁止每次刷新随机生成山体/星图；每个图层列明坐标系、遮挡对象、输入参数及预算。
3. 不允许为了让画面“丰富”擅自增加粒子、光晕、漂浮卡片、动画库或持续循环。视觉缺陷优先删减，其次调整，再考虑增加。
4. 运行时 AI 输出只能映射到预定义文字、草稿、查询卡片和确认动作；不执行模型生成的 HTML/CSS/JS、组件名或动画参数。无效数据保留用户输入并给可恢复提示。
5. 环境引擎只消费验证后的时间/天气/位置数据；模型回答不直接改变天色、天气、提醒级别或事件保存状态。
6. 代码审查与视觉审查分开；实现代理不能以自己的单测或主观描述给自己的画面最终批准。独立审查不可用时保留待审状态，不阻止修复已知问题。

## 实施与验收顺序

1. 先做静态样板：晨光、白天、夕照、夜间；修好同一构图的光照变化，关闭装饰动画也应成立。
2. 完成坐标与遮挡：桌面 1440×900、手机 390×844、窄屏 320×568、横屏 844×390；岸线/反光一致，主体不意外裁掉，正文 200% 缩放不遮住操作。
3. 逐项启用水光、云、天气；不一次叠加验收。每项录制正常速度与慢放片段，检查循环接缝、消失和重新进入。
4. 再叠提醒、事件、查时和 AI；验证日夜、阴雨下文字对比、反向开合、保留草稿、信息退场、确认后停止增强。
5. 记录性能、后台/恢复、减少动态效果；沿用 Harness 预算，超过预算先降粒子/分辨率，不能牺牲输入响应。

证据存入 `docs/evidence/<revision>/`，列出视口、环境输入、运行代码版本、截图/录屏、结论及未测项。没有录屏和交互证据不能称动画成熟；当前这些后续验收为 NOT_RUN。不要把 docs/web/api PASS 写成视觉 PASS。

任务分工建议：场景负责人先修坐标/静态美术；交互负责人修提醒局部强调与面板退场；协调者串行维护共享 token/入口；独立审查者验证最终画面和录屏。各任务只写自己模块，合并后再统一验收。
