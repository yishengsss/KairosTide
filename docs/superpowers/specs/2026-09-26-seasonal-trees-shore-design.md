# 树木与岸边季节表现

## 目标

让首页 Canvas 的树木与岸地能被直观看出随当前季节变化，同时保留稳定构图、连续日光与真实天气因果。

## 范围

- 调整 `apps/web/src/scene/flow/season.ts`、`painter.ts` 与场景测试；必要时调整 `palette.ts` 的岸地季节混色。
- 使用现有 `EnvironmentFrame.season.progress` 连续插值，不增加季节切换按钮或离散背景。
- 树叶季节色差需要在清晨/傍晚仍可辨；树冠与灌木覆盖仅作克制的疏密变化，位置和数量保持固定、确定。
- 岸边色彩/植被感使用同一季节进度，不能只按昼夜光照改变。
- 冬季季节状态在地面形成稳定白雪覆盖；空中降雪粒子仍只由天气输入驱动。季节积雪不伪称当前正在降雪。
- 不改变地形山脊、太阳/天空轨迹、工作态、提醒态或 HTML Demo 控件。

## 视觉映射

- 春：较清新的嫩绿，覆盖由疏向密。
- 夏：较饱和的绿与最完整覆盖。
- 秋：金黄、赭色系，覆盖适度减少。
- 冬：低饱和、偏灰绿，树冠/岸植稍疏，岸坡和地面呈稳定白雪覆盖。
- 季节颜色与太阳高度/天气分别作为输入组合，确保阴雨不会被季节颜色覆盖，日照变暗也不抹掉季节色相。

## 验收

1. 固定四个季节采样，树叶与岸地均有可辨差异；同一输入重复绘制几何完全稳定。
2. 树根仍贴合岸坡；树冠覆盖随季节轻微变化，不出现突变、飘叶或随机重排。
3. 天气、日照变化不改季节类别；冬季地面积雪来自季节状态，空中降雪仍来自天气状态。
4. 场景测试和 Web 构建通过；浏览器对比四季与晨昏，代码测试不能代替视觉验收。
