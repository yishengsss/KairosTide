## 评价方法

离线门禁：非法输出、无需确认写入、密钥泄露路径、柔性任务擅自分配时间均零容忍；这些约束由程序测试保证，不只依赖模型服从。

在线基线：每个真实语言样本运行 3 次，记录正确率、澄清准确率、拒绝准确率、延迟、token 用量、供应商和模型标识。第一版要求关键日期/时长字段全部符合预期后进入人工演示；任何失败保留原样本并修复，不用平均分掩盖错误。

每次更换模型、提示词或输出结构重新运行；未选供应商前在线结果记为“未运行”。真实密钥缺失不阻塞确定性事件引擎开发。
