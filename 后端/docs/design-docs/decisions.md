# 设计决策记录

2026-09-25，状态：规划建议。产品范围已来自用户；以下是实现选择，不代表用户逐项指定。

## D01：轻量单体 + SQLite

候选：轻量单体、分服务加队列、直接接入通用 Agent 框架。选择轻量单体作为第一版基线：项目只有单用户固定事件，无需增加服务间一致性或自主工具执行。代价是暂不支持多实例写入及公网多用户规模。

建议 Python 3.12 + FastAPI + Pydantic + SQLite，使用 uv 锁定依赖。版本可在启动阶段根据环境验证调整，并记录原因；不得未经验证声称已安装或兼容。

## D02：先规则，后模型

确定性时间引擎先完成，再接入可替换 Planner。假模型仅用于测试，不得把假模型模式标作“AI 已接通”。模型故障不能影响现有事件。

## D03：轻量 Harness

建立短 AGENTS、架构地图、契约、执行计划、质量门禁及状态账本。检查与 CI 在 M1/M6 实现；当前只有规划。避免只增加文档却没有反馈路径，也避免在原型阶段搭建完整监控平台。

## D04：草稿确认与原子提交

沿用第一版规划：AI 产出草稿，用户确认后保存。多事件录入整批成功或失败。模型请求不占数据库事务；提交时复检，避免预览与保存之间的竞争条件。

## D05：系列修改保护例外

标题、地点等非时间信息可以原位修改；已有请假/取消例外的系列若修改时区、重复规则或开始时间，第一版返回 SERIES_HAS_EXCEPTIONS，要求先在管理页明确处理系列。暂不实现自动迁移例外日期，以免一次请假错位到另一堂课。

## D06：有限窗口冲突检测

无限重复系列无法用有限展开证明永不冲突。候选提交检查从最早新实例开始的 90 天，返回检查窗口和“不覆盖全部未来”的标志；发生冲突时不自动调整时间。前端必须展示窗口，不能宣称永久无冲突。/state 对实际当时的全部有效实例始终返回冲突结果。

## 剩余选择

- AI 供应商、模型、账户与费用：由用户选定；前五阶段可用假 Planner 独立推进。
- 外部访问与多用户：当前不支持；出现新需求时另立设计。
- 系统关闭状态下的通知：当前不支持；不能作为第一版验收承诺。
