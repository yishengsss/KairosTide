# 长按查时提示样式收敛

## 目标

让临时真实时间清楚易读，同时与自然场景相融，不像独立的玻璃浮窗。

## 范围

- 只调整 `apps/web/src/App.vue` 中 `.time-peek` 的视觉样式。
- 保留靠近长按起始点、优先显示在触点上方、空间不足时向下避让的行为。
- 保留真实本地时间、约三秒显示、跨分钟刷新、现有淡入淡出和减少动态效果行为。
- 不增加图标、标签、卡片内容或其他时间入口；不改变长按阈值和命中范围。

## 视觉方案

- 使用紧凑的时间数字，保留等宽数字和当前系统字体。
- 移除渐变背景、边框、发光与多层阴影；不使用 16px 重玻璃模糊。
- 若纯文字在明亮天空上对比不足，使用一层克制的深色半透明底和单层柔和阴影。
- 背景只包裹数字，不保留宽大的固定最小宽度；圆角与内边距低调。
- 保持现有轻微位移/淡化逻辑，不新增弹跳、缩放幅度或动画时长。

## 验收

1. 长按位置、边缘避让、三秒显示和真实时间读取测试不变。
2. 暗色夜空和较亮天空上均能快速读出时间。
3. 提示不遮挡主要事件信息，视觉重量明显低于 AI 面板和事件卡片。
4. 减少动态效果下不发生位移，静态文字仍可读。
